# w/ — 진척도 홈위젯 데이터

안드로이드 홈위젯이 읽는 최소 JSON. **여기엔 숫자와 한 줄 요약만 둔다.**

- 담는 것: 전체 %, 큰틀 4개 이름·%, 갱신일, "지금 할 일" 한 줄
- **담지 않는 것**: 직원 이름, 금액, 거래처, 상장요건, 인증 상세, 파일 경로 — 상세는 로그인 뒤 아티팩트에만 있다.
- 파일명이 곧 열쇠(추측 불가 32자). 앱 UI 어디에도 링크하지 않는다. 노출되면 파일명을 바꾸고 위젯 앱의 URL을 함께 고칠 것.
- 갱신: "진척도 갱신해" 시 진척도 HTML 3종과 함께 이 파일도 고치고 push하면 Netlify가 자동 배포한다.
