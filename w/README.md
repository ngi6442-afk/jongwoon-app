# w/ — 진척도 홈위젯 데이터

안드로이드 홈위젯이 읽는 최소 JSON. **여기엔 숫자와 짧은 작업 라벨만 둔다.**

- 담는 것: 전체 %, 큰틀 4개 이름·%, 갱신일, "지금 중요한 순서" 5개(짧은 작업 라벨)
- **담지 않는 것**: 직원 이름, 금액, 거래처, 상장요건 수치, 인증 상세, 파일 경로, 버전 번호 — 상세는 로그인 뒤 아티팩트에만 있다. todos는 "직원 PIN 발급" 수준의 작업 라벨까지만(이름·금액 금지).
- 파일명이 곧 열쇠(추측 불가 32자). 앱 UI 어디에도 링크하지 않는다. 노출되면 파일명을 바꾸고 위젯 앱의 `DATA_URL`을 함께 고칠 것.
- 배포용 APK(pw-*.apk)를 여기 임시로 두기도 한다 — 설치 후 지운다.
- 갱신: "진척도 갱신해" 시 진척도 HTML 3종·모바일 아티팩트와 함께 이 JSON의 overall·blocks·todos를 고치고 push하면 Netlify가 자동 배포. 위젯은 다음 주기나 새로고침 탭에 반영(앱 재설치 불필요).
