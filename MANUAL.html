종운 업무 플랫폼 — 사용 안내

종운환경 · 종운건설 공용 / 문의: 나경일 과장

1. 로그인과 알림 (처음 한 번)

① 받은 주소로 접속 → 이름 선택 + PIN 입력 → 로그인
② 새 기기는 관리자 승인 후 사용 가능(승인 요청이 자동으로 감)
③ 오른쪽 위 ⚙ → 로그인 창 맨 아래 [🔔 이 기기 알림 켜기] → 브라우저 "허용" — 지시·승인·개찰 알림이 카톡처럼 옵니다
④ 휴대폰: 크롬에서 접속 → 메뉴 → 홈 화면에 추가 후 알림 켜기 (아이폰은 홈 화면 추가한 경우만 알림 지원)

2. 지시 (매일 보는 곳)

· 내게 온 지시: 내가 담당인 일. 끝냈으면 완료 체크 → 지시자에게 승인 요청이 감
· 승인되면 "승인됨", 반려되면 "반려" 알림이 옴 — 반려면 내용 확인 후 다시 진행
· 기한 있는 지시는 기한 내 처리. 만기(차량 검사·보험, 인허가) 지시는 자동으로 생성됨

3. 계약 진행 (단계가 서류를 이끕니다)

계약마다 단계(적격심사→계약서류→착공→신고→준공→청구→수금)가 지시로 내려옵니다.
각 단계 지시의 [서류] 버튼을 누르면 그 단계에 맞는 서류 생성 화면이 자동으로 열립니다 — 서류 종류를 찾아다닐 필요 없음.
단계자동 생성 서류
적격심사신청서·심사표·각서·확약서(한글) + 자기평점 자동 계산
계약서류계약이행서약서 + 사용인감계(한글)
착공착공계 일습(공문·공정표·직접시공계획서·현장대리인계 등 12서식)
노동부신고석면해체계획서 / 해체신고서
폐기물폐기물배출신고서(수탁확인 포함)
준공준공계 일습(검사원·청구서 포함)
💡 첨부가 먼저입니다. 계약서·석면조사서·건축물대장·사업자등록증(신분증)을 계약 카드의 서류함에 첨부하면 자동 판독해서 서류 빈칸을 채웁니다. 값이 이상하면 검수 화면에서 고치고 확정하세요. 생성 시 "확인요망"이 뜨는 값만 직접 입력하면 됩니다.

4. 서류 생성 후

· 내려받은 파일(xlsx/한글)을 열어 값이 맞는지 한 번 훑고 인쇄·날인·제출
· 노동부 전산 제출용은 엑셀/한글에서 "PDF로 저장" 한 번
· 내역서 낙찰률 적용본은 열었을 때 도급액이 낙찰가와 다르면 → 생성 화면의 "정밀 안착"에 총원가·이윤 입력 → 알려주는 값으로 이윤 셀만 수정

5. 기성(수금) — 담당자만

· 세금계산서 발행하면 계산서 체크, 입금 확인되면 입금완료 — 계약 종결까지 자동 연결
· 홈택스 매출 목록(.xlsx)을 올리면 자동 등록/대사 — 올리기 전 회사(환경/건설) 선택 필수
· 월말: [📤 세무 내보내기]로 그 달 매출 장부를 뽑아 세무사 전달

6. 차량·인허가

검사·보험·면허 만료일만 정확히 입력해두면 30일 전에 자동으로 지시와 알림이 갑니다.

7. 하지 말 것

· 서버에 등록된 양식 원본을 임의 교체하지 않기(관리자만) — 서류 전체가 틀어집니다
· 중복·이상해 보이는 데이터를 임의 삭제하지 않기 — "중복 의심" 칩이 뜨면 담당자 확인 후 처리
· 판독 결과를 검수 없이 그대로 제출하지 않기

8. 문제가 생기면

① 새로고침(F5) → ② 그래도 이상하면 화면·상황을 그대로 캡처해서 나경일 과장에게. "뭘 눌렀더니 뭐가 나왔다"만 있으면 바로 고칩니다.
