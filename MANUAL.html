1. 시작하기 — 로그인과 화면 구성 ↑ 목차

로그인

  1. 받은 주소로 접속합니다.
  2. 이름을 고르고 PIN을 입력합니다.
  3. 새 기기는 관리자 승인 후에 쓸 수 있습니다. 승인 요청은 자동으로 갑니다.

휴대폰에서 쓰실 때

  1. 크롬(아이폰은 사파리)으로 접속합니다.
  2. 메뉴에서 홈 화면에 추가를 누릅니다.
  3. 홈 화면 아이콘으로 들어가 쓰시면 됩니다. 아이폰은 홈 화면에 추가해야 알림을 받을 수 있습니다.

화면은 네 묶음입니다. (권한에 따라 보이는 탭이 다릅니다 — 대부분의 직원은 아래 중 일부만 보입니다. 안 보이는 게 정상입니다.)

  • 관리 — 지시 / 기성·수금 / 거래처 / 인사·직원 / 인사·일용직
  • 수주 — 입찰 / 계약 / 견적서 / 부동산
  • 업무 — 캘린더 / 차량 / 인허가 / 문서함
  • 개인 — 내 업무 / 휴가
권한은 회원마다 탭별로 숨김 / 보기 / 처리 중 하나로 정해져 있습니다. 서버에서 막기 때문에 화면을 조작해서 우회할 수 없습니다. 누가 무엇을 했는지는 감사로그에 자동으로 남습니다.

2. 알림 켜기 (기기마다 한 번씩) ↑ 목차

가장 중요합니다. 알림은 [🔔 이 기기 알림 켜기]를 누른 기기에만 갑니다. 켜지 않은 기기에는 아무 알림도 발송되지 않습니다. 회사 PC에서 켰다고 휴대폰에 오지 않습니다. 쓰시는 기기마다 각각 켜 주세요.

켜는 방법

  1. 로그인 창 맨 아래의 [🔔 이 기기 알림 켜기]를 누릅니다.
  2. 브라우저가 물어보면 허용을 누릅니다.
  3. 기기를 바꾸거나 새 휴대폰을 쓰시면 그 기기에서 다시 켜 주세요. 한 사람당 5대까지 등록됩니다.

이럴 때 알림이 옵니다.

  • 나에게 지시가 등록됐을 때 (담당자에게)
  • 담당자가 지시를 완료 체크했을 때 (승인권자에게)
  • 내 지시가 승인 또는 반려됐을 때 (담당자에게)
  • 계약 단계 완료 요청이 올라왔을 때 (승인권자에게)
  • 입찰 개찰 결과가 확인됐을 때 (관리자 전원)
  • 만기 지시가 자동 생성됐을 때 (관리자)

알림을 누르면 앱 화면으로 바로 이동합니다.

알림이 안 온다고 느끼시면, 대부분 그 기기에서 알림 켜기를 안 누른 경우입니다. 다시 한 번 눌러보세요.

3. 홈 (대시보드) ↑ 목차

직원 홈 — "오늘 내 것"
직원이 로그인하면 홈에 오늘 내 것만 모입니다. 대부분의 하루는 홈에서 끝납니다.

  1. 📌 내게 온 지시 — 눌러서 바로 완료 체크(승인 요청이 갑니다) 또는 보류.
  2. ✅ 이번 주기 체크 — 내 담당 정기 점검. 눌러서 체크하면 됩니다.
  3. 🗒 내 할 일 — 개인 메모형 할 일. 홈에서 바로 추가·완료·삭제.
  4. 하단 휴가 신청(잔여 연차 표시)·캘린더 타일.

관리자 홈은 회사 전체가 보이는 화면입니다 — KPI 타일(진행 계약·미수·기한), 파이프라인 보드(수주→계약·서류→시공 중→기성·수금), 승인 대기함(지시 결재·휴가 승인·청구 검수), 만기 임박 목록, 오늘 흐름 피드. 보드의 카드를 클릭하면 해당 탭으로 넘어갑니다.

4. 지시 — 매일 보는 곳 ↑ 목차

무엇을 하는 곳인가
회사의 모든 할 일이 모이는 곳입니다. 사람이 직접 낸 지시뿐 아니라, 계약 단계와 만기 건도 자동으로 지시가 되어 여기로 옵니다.

자주 하는 일

  1. 내게 온 지시에서 내가 담당인 일을 확인합니다.
  2. 일을 끝냈으면 완료 체크를 누릅니다. 지시자에게 승인 요청이 갑니다.
  3. 승인되면 "승인됨", 반려되면 "반려" 알림이 옵니다. 반려면 내용을 확인하고 다시 진행합니다.
  4. 계약 단계 지시라면 📄 서류 버튼을 눌러 그 단계의 서류를 바로 작성합니다.
  5. 기한이 있는 지시는 기한 안에 처리합니다.

주의

  • 완료 체크는 "다 했습니다"라는 요청입니다. 승인권자가 승인해야 끝난 것으로 처리됩니다.
  • 만기 지시(차량 검사·보험, 인허가, 증명서 갱신 등)는 자동으로 생깁니다. 지웠다가 다시 만들지 마시고 그대로 처리하세요.
  • 지시 탭이 안 보이는 분도 정상입니다 — 내게 온 지시는 홈과 내 업무 탭에서 받고 완료하면 됩니다. 지시 등록·전체 목록은 관리자 화면입니다.

5. 계약 파이프라인 — 단계가 서류를 이끕니다 ↑ 목차

이 회사 시스템에서 가장 중요한 개념입니다. 서류 종류를 찾아다니지 않습니다. 계약이 지금 어느 단계인지가 정해지면, 그 단계가 필요한 서류를 알아서 띄워줍니다.

5-1. 계약을 시작하면 단계가 자동으로 짜입니다

계약을 시작할 때 이 공사에 해당하는 요소를 체크합니다.

석면철거 · 노동부신고 · 일반철거 · 대형철거 · 폐기물 · 준설 · 적격심사

체크한 요소에 맞춰 단계가 자동으로 조립됩니다. 발주처가 어디냐가 아니라 어떤 요소가 들어있느냐가 단계를 결정합니다. 마지막 두 단계는 어떤 계약이든 항상 청구 → 수금확인입니다.

5-2. 단계 = 지시

  1. 현재 단계가 지시 탭에 할 일로 발행됩니다.
  2. 담당자가 그 지시의 📄 서류 버튼을 눌러 서류를 만듭니다.
  3. 일이 끝나면 완료 체크 → 승인권자에게 알림이 갑니다.
  4. 승인되면 다음 단계가 자동으로 생성됩니다.
  5. 잘못 넘어갔으면 되돌리기 ↩로 직전 단계로 돌아갑니다. 실수 방지를 위해 한 번 더 확인합니다.

5-3. 어느 회사 이름으로 나가나 (두 회사 규칙)

일의 종류시행 회사
철거 · 석면㈜종운건설
폐기물 · 준설(유)종운환경
철거·석면 공사 안의 폐기물 신고·운반 서류(유)종운환경

서류를 만들 때 이 규칙대로 회사가 자동 선택됩니다. 필요하면 수동으로 바꿀 수 있지만, 바꾸기 전에 위 표를 확인하세요.

5-4. 입찰에서 넘어온 계약

입찰 탭에서 낙찰 처리를 하고 계약으로 전환하면, 공고명·기관·낙찰금액이 계약에 자동으로 들어옵니다. 다시 입력하지 마세요.

5-5. 돈으로 끝나는 흐름

  1. 청구 단계를 승인하면 "기성(미수) 등록할까요?"라고 승인권자에게 물어봅니다.
  2. 예를 누르면 기성·수금 탭에 청구 건이 자동으로 생깁니다(계약과 연결됨).
  3. 관리자가 계산서 발행을 체크하고, 입금이 들어오면 입금 처리를 합니다.
  4. "수금확인 단계 완료할까요?"가 뜨고, 완료하면 계약이 종결됩니다.
  5. 계약 카드에 💰 수금완료 또는 미수 칩이 표시됩니다.

종결된 계약은 자동으로 실적이 됩니다. 계약 탭의 실적 다운로드로 공사명·발주처·공종·요소·금액·착공/준공·수금일·시행회사·연면적이 담긴 엑셀을 받을 수 있습니다. 실적증명이나 기술평가 근거로 씁니다.

6. 서류 자동 생성 — 무엇이 채워지고 무엇을 봐야 하나 ↑ 목차

어떻게 돌아가나

  1. 관리자가 + 양식 등록으로 원본 양식 파일을 서버에 올려둡니다. 이 원본은 절대 건드리지 않고 보관합니다.
  2. 직원이 📄 서류를 누르면, 원본을 복사한 뒤 값만 갈아끼웁니다.
  3. 그래서 서식·도장 자리·도형·인쇄 설정이 원본과 100% 똑같이 나옵니다.
  4. 앱이 모르는 값만 생성 직전에 "확인요망" 목록으로 물어봅니다. 그것만 채우면 됩니다.
값이 채워지는 순서는 ① 앱이 알아서(자동 조회·기존값) → ② 첨부 파일 판독 → ③ 사람이 직접 입력(최후) 입니다. 그래서 첨부를 먼저 올리는 것이 손이 제일 덜 갑니다(7절 참고).

6-1. 서류별 — 자동으로 채워지는 것 / 사람이 확인할 것

서류자동으로 채워지는 것사람이 꼭 확인할 것
착공계 일습
(착공 단계)		 공사명·주소·한글금액·날짜 등 기본정보가 공문·공정표(공종별 세트)·직접시공계획서·현장대리인계 등 12개 서식에 전파 현장대리인은 일용직 명부에서 사람이 고릅니다. 공정표 막대(색칠)는 자동이 아니므로 직접 채웁니다.
준공계 일습
(준공 단계)		 착공계 항목 + 준공검사원 + 청구서(계좌·금액) 청구 계좌가 맞는지 확인하세요. ㈜종운건설 청구 계좌는 아직 자동 등록되지 않습니다.

해체신고서
(완료신고 포함)		 관리자·위치·해체기간, 동별 개요는 건축물대장 데이터. 위임장·해체공사계획서·완료신고까지 값이 전파 해체기간(착수~종료일)이 실제 일정과 맞는지, 대장 조회 결과가 현재 건물과 맞는지.
폐기물배출신고서
(수탁확인 포함)		 발주자(신분증·사업자등록증 판독), 용역명, 현장, 폐석면/부자재 톤수, 제출년월, 수신처(주소에서 시장/군수 자동). 수탁확인서 1·2p·유해성자료까지 전파. 시행 회사는 종운환경 고정 톤수는 아직 자동 계산이 아닙니다. 반드시 직접 확인해서 넣으세요. 수신처(시장/군수)도 한 번 보세요.
적격심사 패킷
(한글 파일)		 별지1 신청서+접수증·별지2 심사표·별지4 각서·별지5 이행확약서 일체. 공고번호·입찰일·낙찰금액·A값·예정가격·구간·등급 프리필, 자기평점 자동 계산 기준 세트(교육청 2023 / 지자체 별표7) 중 맞는 것이 선택됐는지. 평점 근거가 되는 증빙을 실제로 갖고 있는지.
계약서류 2종
(한글 파일)		 계약이행 통합서약서 + 사용인감계. 계약명·보증기간(계약일~준공일)·한글/숫자 금액·보증금(률×금액)·회사별 상호/연락처/사업자번호·수신처 제안 입찰 건은 6·7번 체크를 직접 수정해야 합니다(안내가 뜹니다). 수신처 제안이 맞는지도 확인.
선금지급신청 세트
(한글 파일)		 공문 + 별첨2 신청서 + 별첨3 각서 + 별첨4 사용계획 + 별첨5 청구서 + 지급조건 일체. 차액·적용요율·잔액·사용계획 소계/부가세·한글금액 전부 자동 계산 넣은 금액이 맞는지. 요율이 50%를 넘으면 경고가 뜨는데, 뜨면 그냥 넘기지 말고 확인하세요.
견적서
(한글 파일)		 회사별 사내 공식 양식 자동 선택. 금액(수량×단가)·한글금액·견적번호·일자 자동. 합계는 한글 계산식이 살아 있음 수신처·용역명·품목·부가세 구분은 직접 입력합니다. 품목을 2행째부터 손으로 추가하면 합계는 한글에서 자동 합산됩니다.
계약서
(비입찰·개인 건)		 발주처·주소·금액만 넣으면 생성. 증빙을 첨부했으면 갑란 자동. 생성 후 계약에 저장 → 대장 자동 조회 → 계약 단계 완료 → 후속 서류 일괄 생성 제목의 ☑석면해체 / ☑철거공사 체크가 맞는지. 개인 사문서는 착공계·준공계가 만들어지지 않습니다(정상입니다).
내역서 낙찰률 적용 생성 → 내역서 낙찰률 적용. '단가' 열 숫자만 낙찰률을 곱해 내림 처리(수식은 보존) 파일을 열어 도급액이 낙찰가와 맞는지 보세요. 다르면 "정밀 안착"에 총원가·이윤을 입력하면 "이윤 셀을 N으로 수정"이라고 정확한 값을 알려줍니다.

6-2. 서류를 받은 다음

  1. 내려받은 파일(엑셀 / 한글)을 열어 값이 맞는지 한 번 훑습니다.
  2. 인쇄하고 날인해서 제출합니다.
  3. 전산 제출용은 엑셀·한글에서 "PDF로 저장"을 한 번 하시면 됩니다.
판독 결과를 검수 없이 그대로 제출하지 마세요. 자동으로 채워진 값도 사람이 최종 책임을 집니다.

7. 서류함과 자동 판독 (첨부가 먼저) ↑ 목차

무엇을 하는 곳인가
계약 카드 안의 서류함입니다. 여기에 파일을 올려두면 앱이 내용을 읽어서 서류 빈칸을 대신 채웁니다.

자주 하는 일

  1. 계약 카드를 엽니다.
  2. 서류함에 파일을 드래그하거나 버튼으로 첨부합니다.
  3. 파일 이름으로 종류가 자동 분류되고, 뒤에서 판독이 돕니다. 30초~2분 걸립니다.
  4. 석면조사서는 검수 모달이 뜹니다. 값을 보고 고친 뒤 확정을 누릅니다.
  5. 확정하면 "석면해체계획서 생성할까요?"라고 바로 물어봅니다.
파일 이름에 이 말이 들어가면이렇게 읽습니다
석면 / 조사석면조사서 — 자재표(동·자재·위치·면적·함유율)·의뢰인·연면적을 뽑고, 노동부 신고 대상인지 자동 판정합니다. 검수 모달에서 사람이 확정합니다.
계약계약서 — 공사명·금액·계약/착공/준공일·발주자·주소를 뽑고, 계약 단계 자동 완료와 착공계 작성을 제안합니다.
대장건축물대장 — 용도·구조·연면적·층수·승인일을 뽑습니다.
등록증 / 신분증발주처 증빙 — 상호(성명)·대표·사업자번호(개인은 생년월일)·주소를 뽑습니다. 주민번호 뒷자리는 추출하지 않습니다.
건축물대장은 직접 첨부하지 않아도 됩니다. 계약 카드의 대장 버튼을 누르거나(지번 주소 필요), 계약서를 판독할 때 자동으로 조회됩니다. 조회되면 카드에 🏢 칩이 붙습니다.
파일 이름이 엉뚱하면 엉뚱하게 분류됩니다. 첨부 전에 파일 이름에 "석면조사", "계약서", "대장", "사업자등록증" 같은 말이 들어가 있는지 확인해 주세요.

8. 견적서 권한 필요 ↑ 목차

이 탭은 기본적으로 숨겨져 있습니다 — 견적 발행을 담당하는 분(영업)에게만 권한이 부여됩니다. 안 보이면 정상입니다. 계약 파이프라인의 "견적" 단계 서류는 이 탭과 무관하게 계약 권한으로 만들 수 있습니다.

무엇을 하는 곳인가
견적서를 발행하고 문서번호를 관리하는 전용 탭입니다. 계약 파이프라인과는 별개입니다. 아직 계약이 없는 건도 여기서 견적서를 낼 수 있습니다.

자주 하는 일

  1. 새 견적을 만듭니다. 견적번호는 자동으로 붙습니다(YYYYMM-일련번호, 그 달 발행분 중 제일 큰 번호 +1).
  2. 수신처·용역명·품목·수량·단가를 넣습니다. 금액과 한글금액은 자동으로 계산됩니다.
  3. 저장하면 발행 이력에 번호 역순으로 쌓입니다. 내부 메모는 따로 적는 칸이 있습니다.
  4. 필요할 때마다 행에서 한글 파일 재발행을 눌러 다시 내려받습니다. 회사별 양식은 자동으로 골라집니다.
  5. 일이 성사되면 계약 생성을 눌러 계약으로 승격합니다. 회사에 맞는 유형·요소로 계약이 시작되고, 견적에는 계약 연결 칩이 붙습니다.

주의

  • 번호는 손으로 고칠 수 있지만, 중복이면 경고가 뜹니다. 경고를 무시하지 마세요.
  • 일자를 바꾸면 그 달 기준으로 번호가 다시 매겨집니다.
  • 삭제는 완전 삭제가 아니라 숨김입니다. 잘못 지웠으면 관리자에게 시점 복구를 요청하세요.
수의계약 요소를 체크한 계약이라면 파이프라인에 "견적" 단계가 자동으로 생기고, 그 단계의 📄 서류에서도 견적서를 만들 수 있습니다. 계약과 무관하게 발행할 때만 견적서 탭을 쓰시면 됩니다.

9. 기성·수금 ↑ 목차

무엇을 하는 곳인가
청구한 돈이 들어왔는지 관리하는 곳입니다. 흐름은 청구 생성 → 검수 → 계산서 발행 → 입금 → (안 들어오면) 미수 추적입니다.

자주 하는 일

  1. 계약의 청구 단계가 승인되면 기성 건이 자동으로 생깁니다. 새 청구에는 "검수 대기" 칩이 붙습니다.
  2. 관리자가 청구 금액을 확인하고 검수를 누릅니다 — 누가 언제 검수했는지 기록되고 "검수 ✓"로 바뀝니다.
  3. 세금계산서를 발행했으면 계산서 발행을 체크합니다.
  4. 입금이 확인되면 입금 처리를 합니다. 그러면 "수금확인 단계 완료할까요?"가 떠서 계약 종결까지 이어집니다.
  5. 세금계산서 목록 파일(.xlsx)을 올리면 여러 건이 한 번에 등록·대사됩니다.
  6. 월말에 📤 세무 내보내기(월)로 그 달 매출 장부를 뽑아 세무사에게 전달합니다.

주의

  • 검수·계산서 발행·입금 처리는 관리자만 할 수 있습니다(서버가 강제). 검수 전 건을 입금 처리하려 하면 경고가 뜹니다.
  • 밀린 검수는 관리자 홈의 승인 대기함에 "청구 검수 n건"으로 모입니다.

세금계산서 목록 업로드는 이렇게 동작합니다.

  • 홈택스와 위하고 두 포맷을 모두 자동으로 알아봅니다.
  • 공급자 사업자번호를 보고 행마다 시행 회사를 자동 판별합니다. 파일 단위로 회사를 고를 필요가 없습니다.
    506-81-48535 = 종운환경 / 506-81-84827 = 종운건설
  • 매입분(입/출구분)은 자동으로 빠집니다.
  • 승인번호를 기준으로 대사합니다. 새 건은 추가, 금액이 바뀐 건은 갱신, 취소분은 숨김 처리됩니다.
  • 한 파일 안에 중복이 있으면 지우지 않고 따로 보여줍니다. 사람이 보고 판단하시면 됩니다.

주의

  • 회사 구분(환경/건설)이 비어 있는 옛날 건도 파일을 다시 올리면 소급해서 채워집니다.
  • 세무 내보내기 파일은 앱에 들어있는 값 그대로입니다. 앱이 임의로 추정 계산하지 않습니다. 그래서 앱 값이 틀리면 장부도 틀립니다.
  • 청구한 지 45일이 지나면 미수 장기화 지시가 자동으로 생기고 알림이 갑니다.

10. 거래처 ↑ 목차

무엇을 하는 곳인가
발주처·협력사 등 거래처 정보를 모아두는 곳입니다. 여기에 정리해 둔 정보가 다른 탭에서 쓰입니다.

자주 하는 일

  1. 거래처를 새로 등록하거나 기존 정보를 수정합니다.
  2. 필요한 거래처를 찾아 연락처·정보를 확인합니다.

주의
상호·사업자번호를 정확히 넣어두세요. 서류에 그대로 나갑니다. 삭제는 임의로 하지 마시고, 이상해 보이면 담당자에게 알려주세요(잘못 지운 경우 관리자 시점 복구로 되돌릴 수 있습니다).

11. 입찰 관리자 ↑ 목차

무엇을 하는 곳인가
여러 사이트의 공고를 자동으로 모아 보여주는 곳입니다. 나라장터·수자원·국방·누리·순환·K-apt·LH·철도·한수원·포스코·온비드에서 평일 아침에 자동 수집됩니다.

자주 하는 일

  1. 아침에 새로 올라온 공고를 훑습니다.
  2. 관심 건의 낙찰하한가 계산기와 투찰범위 칩으로 투찰 금액을 잡습니다.
  3. 관심 없는 건은 패스합니다. 같은 기관에서 비슷한 제목으로 다시 올라오면 자동으로 패스됩니다.
  4. 개찰 결과(낙찰/유찰)는 자동으로 확인되고 관리자 전원에게 알림이 갑니다.
  5. 낙찰되면 계약으로 전환합니다. 공고명·기관·낙찰금액이 계약에 자동으로 넘어갑니다.

주의

  • 하한율·예가범위·A값은 공고문에 적혀 있는 것만 읽어옵니다. 없으면 비어 있습니다. 임의로 추정하지 않습니다.
  • 계산기 결과는 참고값입니다. 투찰 전에 공고문 원문을 반드시 확인하세요.
적격심사 대상 건이 낙찰되면, D-7 지시(별표3 체크리스트 포함)가 자동으로 뜨고, 배너의 계약 시작을 누르면 값이 전부 프리필된 상태로 적격심사 패킷 작성까지 이어집니다.

무엇을 하는 곳인가
온비드에서 자동 수집한 부동산 물건을 보는 곳입니다. 입찰 수집과 같은 방식으로 평일 아침에 채워집니다.

자주 하는 일

  1. 새로 올라온 물건을 확인합니다.
  2. 관심 없는 건은 넘깁니다.

주의
화면에 보이는 정보는 수집된 내용입니다. 실제 투찰 전에는 반드시 온비드 원문을 확인하세요.

13. 인사·직원 관리자 ↑ 목차

무엇을 하는 곳인가
직원 명부와 연차를 관리하는 곳입니다. 권한관리·감사로그·시점 복구도 여기 있습니다(21절 참고).

자주 하는 일

  2. 연차 현황을 확인합니다.

14. 인사·일용직 ↑ 목차

무엇을 하는 곳인가
석면·철거 현장에 투입되는 인력 명부입니다. 여기 적어둔 사람이 석면해체계획서 명단과 현장대리인계에 그대로 들어갑니다.

자주 하는 일

  1. 새로 투입되는 인력을 등록합니다. 이름·생년·직책·연락처·검진일을 넣습니다.
  2. 검진일이 바뀌면 갱신합니다.
  3. 서류를 만들 때는 이 명부에서 체크로 인원을 고릅니다.

주의
이름·생년·검진일이 틀리면 신고 서류가 그대로 틀립니다. 서류에 직접 인쇄되는 정보라고 생각하고 정확히 넣어주세요. 이 탭은 권한이 있는 분만 보입니다.

15. 캘린더 ↑ 목차

무엇을 하는 곳인가
회사 일정이 한 곳에 모이는 달력입니다. 따로 입력하는 것이 아니라 다른 탭의 일정이 자동으로 표시됩니다.

여기에 모이는 일정

  • 각종 만기(차량 검사·보험, 인허가)
  • 지시 기한
  • 청구
  • 휴가
  • 차량 현장 출동 🚚

자주 하는 일

  1. 이번 주·이번 달에 무엇이 있는지 봅니다.
  2. 겹치는 일정이 있는지 확인하고 미리 조정합니다.

주의
캘린더에 안 보이는 일정은 원래 탭에 입력이 안 된 것입니다. 캘린더에서 찾지 마시고 해당 탭에서 확인하세요.

16. 차량 ↑ 목차

회사 차량의 만기와 이력을 관리하는 곳입니다.

자주 하는 일

  3. 현장 출동 이력을 기록합니다. 캘린더에 🚚로 표시됩니다.

  • 취득가액·무자료금액은 관리자 전용입니다. 서버에서 막혀 있어 다른 분에게는 아예 내려가지 않습니다.

17. 인허가 ↑ 목차

18. 문서함 ↑ 목차

무엇을 하는 곳인가
회사 공용 문서를 보관하는 곳입니다. 납세·지방세·4대보험 완납증명 같은 증명서도 여기에 올려 둡니다.

자주 하는 일

  1. 발급받은 증명서를 업로드합니다.
  2. 필요한 문서를 찾아 내려받습니다.

주의

  • 증명서는 20일 주기로 갱신 지시가 자동으로 옵니다. 유효기간(30일)과 행정 처리 지연을 감안한 주기입니다. 지시가 오면 발급받아 여기에 올려주세요.
  • 등기부등본은 인정기간 안이면 갖고 있는 것을 다시 쓰고, 만료됐을 때만 새로 발급합니다(유료).
  • 인감증명서는 온라인으로 안 됩니다. 무인발급기나 등기소에서 받아야 합니다.
  • 계약별 서류는 문서함이 아니라 계약 카드의 서류함에 넣어야 판독이 됩니다(7절).

19. 개인 — 내 업무 ↑ 목차

무엇을 하는 곳인가
내 것 세 가지가 모이는 탭입니다: 내게 온 지시(받은 일 완료 체크) · 내 할 일(개인 메모, 본인만 보임) · 주기 체크리스트(담당 정기 점검). 홈의 "오늘 내 것"과 같은 내용의 상세 화면입니다.

자주 하는 일

  1. 내게 온 지시를 확인하고, 끝낸 일은 눌러서 완료 체크합니다(승인 요청이 갑니다).
  2. 기억할 일을 내 할 일에 적어두고, 끝나면 체크합니다.
  3. 내 담당 주기 점검 항목을 체크합니다.

주의
회사 업무는 지시로 받아야 승인·알림이 돕니다. 내 할 일에만 적어두면 나만 압니다.

20. 개인 — 휴가 ↑ 목차

무엇을 하는 곳인가
휴가를 신청하고 승인받는 곳입니다.

자주 하는 일

  1. 휴가 신청을 올립니다.
  2. 승인되면 캘린더에 자동으로 표시됩니다.
  3. 연차 현황은 인사에서 관리합니다(13절).

주의
신청만 하고 승인이 안 난 휴가는 확정이 아닙니다. 캘린더에 떴는지 확인하세요. 연차는 소멸도 이월도 없습니다.

21. 관리자용 기능 관리자 ↑ 목차

이 절은 관리자 권한이 있는 분만 해당됩니다. 일반 직원에게는 화면에 보이지 않습니다.

21-1. 양식 등록

+ 양식 등록으로 원본 양식 파일을 서버에 올려 영구 보관합니다. 서류를 만들 때는 이 원본을 복사해서 값만 바꾸므로, 원본이 바뀌면 그 양식으로 나가는 모든 서류가 한꺼번에 틀어집니다.

  • 양식 교체는 실물 양식과 대조한 뒤에만 하세요.
  • 바꾼 직후에는 서류를 한 건 생성해서 열어보고 확인하세요.

21-2. 권한관리

인사·직원 탭 🔑 권한관리 — 사람×모듈 표에서 칸을 누를 때마다 수행 → 보기 → 숨김이 순환하고, 사람 단위로 1초 뒤 자동 저장됩니다("저장됨 ✓" 표시). 서버가 강제하므로 화면 조작으로 우회할 수 없습니다.

  • 운영 원칙: 직원에게는 자기 것만 — 지시·기성·수금·거래처는 전 직원 숨김(직원은 홈·내 업무 인박스로 자기 지시를 받습니다), 직무 도구(계약·차량 등)만 개방.
  • 견적서는 기본 숨김 — 담당자에게만 수행을 부여하세요.
  • 직원이 "탭이 안 보인다"고 하면 대부분 여기 설정입니다.

21-3. 감사로그

누가 무엇을 바꿨는지 자동으로 기록됩니다. 값이 이상하게 바뀌었을 때 여기서 먼저 확인합니다.

21-4. 백업

매일 05:30에 전체 데이터가 자동으로 저장되고, 저장소에 스냅샷으로 남습니다. 이력이 그대로 남기 때문에 시점별로 되돌릴 수 있습니다.

21-5. 시점 복구

인사·직원 탭의 ⏪ 시점 복구에서 실행합니다. 저장할 때마다 직전 상태가 자동 보존됩니다(최근 20개 + 하루 1개×30일 — 봇 수집은 하루 1개).

  1. 복구할 컬렉션을 고릅니다 — 지시·계약·기성·수금·거래처·차량·인허가·문서·휴가·견적서.
  2. 보존된 버전 목록(저장한 사람·시각·건수)에서 되돌릴 버전을 고릅니다.
  3. 건수 미리보기(현재 vs 복구본)로 확인합니다.
  4. 확인 창에 "복구"를 직접 입력해야 실행됩니다(2단 확인).

복구 직전 상태도 자동 보존되므로 복구 자체를 되돌릴 수 있고, 실행은 감사로그에 남습니다.

21-6. 판독 비용

첨부 판독은 외부 판독 서비스를 씁니다. 문서 한 건에 수십 원 수준입니다. 선불 크레딧이고 자동 충전을 꺼 두었기 때문에 비용이 무한정 늘어나지 않습니다.

22. 하지 말아야 할 것 / 문제가 생기면 ↑ 목차

하지 마세요.

  • 서버에 등록된 양식 원본을 임의로 교체하지 마세요(관리자만). 서류 전체가 틀어집니다.
  • 중복이거나 이상해 보이는 데이터를 임의로 지우지 마세요. "중복 의심"으로 표시된 건은 담당자가 확인한 뒤 처리합니다.
  • 판독 결과를 검수 없이 그대로 제출하지 마세요.
  • 자동으로 생긴 지시(만기·증명서 갱신 등)를 지우고 새로 만들지 마세요. 연결이 끊깁니다.

문제가 생기면

  1. 먼저 새로고침(F5)을 해보세요.
  2. 그래도 이상하면 화면과 상황을 그대로 캡처해서 나경일 과장에게 보내주세요.
  3. "무엇을 눌렀더니 무엇이 나왔다" 이 두 가지만 있으면 바로 고칠 수 있습니다. 원인을 짐작해서 설명하지 않으셔도 됩니다.
아직 자동이 아닌 것들입니다. 이 부분은 직접 확인해 주세요. — 폐기물량(톤) 자동 계산, 공정표 막대 색칠, ㈜종운건설 청구 계좌 자동 입력.
